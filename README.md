<h1 align="center">NexBox</h1>

<p align="center">Android 应用虚拟化沙盒 · <a href="README_EN.md">English</a></p>

## 主要功能

- 应用克隆
- 分组管理
- Xposed 模块
- 设备模拟
- SIM 模拟
- 虚拟定位
- 共享相册
- 应用冷冻

## 待实现

- 谷歌服务
