<h1 align="center">NexBox</h1>

<p align="center">Android application virtualization sandbox · <a href="README.md">简体中文</a></p>

## Features

- App cloning
- Group management
- Xposed modules
- Device simulation
- SIM simulation
- Virtual location
- Shared gallery
- App freezing

## Planned

- Google services
