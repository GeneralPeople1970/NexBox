LSPlant
Project: https://github.com/LSPosed/LSPlant
Commit: d8b5d1dbb664abc606644036822e4bb64547edf6
License: LGPL-3.0
Bundled text: LSPlant-LGPL-3.0.txt
Vendored at src/main/cpp/third_party/lsplant/ and built as the shared library liblsplant.so
(LSPLANT_BUILD_SHARED=ON) so the LGPL library stays replaceable.
NexBox modifications (2026-09-21): added ArtMethod::Size() and GetClassInitializer() to
reflect an ART class initializer without running it first. The extension uses the method
stride discovered by LSPlant and JNI access to Class.methods/Executable fields. Modified
source is included alongside the shared library build, under the same LGPL-3.0 license.
NexBox modifications (2026-10-11): replaced GNU string-literal operator templates with
standard structural template arguments. The symbol helper retains the existing FixedString
type identity, and the trampoline helper retains literal bytes and lengths. Modified and
added sources remain under the same LGPL-3.0 license; the upstream revision is unchanged.
