Virtualization framework lineage
Projects: https://github.com/Black00Z/Blacks-BlackBox
          https://github.com/ALEX5402/NewBlackbox
          https://github.com/asLody/VirtualApp
          https://github.com/didi/VirtualAPK
Bcore retains and adapts the BlackBox framework lineage, including its Android mirror
declarations and package/service virtualization. The current root and BlackBox/VirtualAPK
repositories provide Apache-2.0 notices. Original import revisions and any historical
VirtualApp license terms cannot be inferred from today's repository metadata; the
project credits are preserved without declaring a new license for that historical code.
NexBox's root Apache LICENSE and app's Apache license copies are distributed with the
project. Android/AIDL descendants retain their existing AOSP source headers.
